## 3. 주요 결정 사항

- **LLM 은 로컬 모델(Ollama)을 쓴다.** 팀 API 예산이 없고, temperature·seed 를 고정해 실험 조건을 기록할 수 있다. 단, 상용 모델로의 일반화는 한계로 명시한다 (#21)
- **생성과 실험을 분리한다.** 생성은 각자 PC, 실험은 서버(VM). 생성 결과는 조건(모델·seed 등)과 함께 파일로 남겨 재현한다 (`generated/README.md`)
- **관측하지 못했으면 결과를 내지 않는다.** 장비가 꺼져 검사를 못 한 경우를 "차단"·"반려"로 기록하는 버그가 반복돼(#5, #7, #11) 팀 원칙으로 정했다. 실행 실패는 결과에서 빼고 이유를 따로 기록한다 (`AGENTS.md`)
- **동적 검증 실패는 "고위험"이 아니라 "검증 실패(롤백)"로 분류한다**
- **협업 규칙:** 브랜치 → PR → 팀원 승인 → 승인한 사람이 머지. AI 도구 사용은 팀에 공개하고 위임 범위를 문서화했다 (#25, #27)
