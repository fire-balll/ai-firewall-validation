# 주차별 할 일

팀 프로젝트 계획서(2026-10-09, 6장 일정·4장 역할 분담)를 사람별·주차별로 나눈 것이다. 진행 상태는 **2026-10-29 main(`3744879`) 기준**이다(처음 작성은 10/15 `34979dc`). 중간발표는 교수님 공지로 **11/5(목) → 11/12(목)** 으로 바뀌었다.

- **굵은 글씨**는 계획서의 마일스톤·산출물이다. 나머지 세부 항목과 날짜는 그 마일스톤을 맞추려고 나눈 **제안**이고, 중간발표(11/12) 관련 항목은 계획서에 없어서 모두 제안이다. 팀에서 정하면 고친다.
- 1주차 표에는 끝난 것만 남겼다. 1주차에 끝나지 않은 것은 2주차에 `(1주차 이월)` 로 옮겼다.
- 상태: ✅ 완료(main 반영) · 🔄 진행 중(PR 열림 또는 일부만 끝남) · ⬜ 아직 · ❓ 확인 필요
- 주간 회의록은 [`meetings/`](meetings/) 에 둔다. 다음 주 할 일의 결과는 회의록에 채우고, 이 문서에는 상태만 반영한다.
- ✅ 옆에는 실제로 만든 사람이 담당자와 다르면 출처를 적었다. 프로젝트 스캐폴드(`90322c6`)는 정택준이 올렸고, 각 담당자가 그 위에 고도화했다.
- **"3회 반복" 은 두 가지다.** LLM 생성 후보는 **seed 1·2·3 으로 만든 파일 3개**(생성기 편차)이고 랩에서는 1번씩 돌린다(`--reps 1`). 정답·오류 주입 후보는 **같은 파일을 랩에서 3번**(`batch.py --reps 3`, 랩 편차) 돌린다 (`generated/README.md` "반복 규칙").
