# mutations

정답 룰셋을 일부러 망가뜨린 **오류 주입 룰셋**을 둔다. 생성기 품질과 상관없이 검증기를 평가하기 위한 데이터다. (담당: 서진정)

파일 이름은 `<시나리오>-<유형>-<번호>.json`, 형식은 `schema/rule.schema.json` 과 같다. 스키마에 없는 필드는 거부되므로, 어떤 오류를 넣었는지는 아래 표에 기록한다.

| 유형 | 예시 | 정적 검증으로 잡히나 (가설) |
| --- | --- | --- |
| order | 넓은 drop 이 좁은 accept 보다 앞 | 대체로 잡힘 (shadowing) |
| widen | /32 → /16, 특정 포트 → any | 과도 범위 검사로 잡힘 |
| port | 80 → 8080 | 정답 비교 없이는 안 잡힘 |
| swap | src 와 dst 가 뒤바뀜 | 정답 비교 없이는 안 잡힘 |
| missing | 필요한 accept 룰 누락 | 정적으로는 안 잡힘 |

"가설" 열이 실제로 맞는지 확인하는 것이 실험의 핵심 질문이다.

| 파일 | 원본 | 유형 | 바꾼 내용 |
| --- | --- | --- | --- |
